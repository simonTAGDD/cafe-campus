## Sobre el proyecto

**CaféCampus** es una cafetería universitaria especializada en café colombiano de origen (Quindío, Huila, Nariño y Sierra Nevada), diseñada para estudiantes y docentes que necesitan calidad artesanal sin perder tiempo entre clases.

Este repositorio contiene la plataforma web oficial del proyecto —desarrollada como entrega final de la **Electiva de Inteligencia Artificial**— enfocada en conversión rápida mediante pedidos express por WhatsApp, suscripción mensual con tarjeta digital interactiva y diseño adaptable (*light/dark mode*).

### 2. Bebidas Frías

* **Frappé Final de Semestre** — `$9.500` · Café helado cremoso con caramelo y crema batida.
