## Sobre el proyecto

CaféCampus es una cafetería universitaria de café de origen colombiano, pensada para estudiantes y docentes con poco tiempo entre clases. Este repositorio contiene su página web, desarrollada como proyecto final de la Electiva de Inteligencia Artificial.

## Propuesta de valor

Café de calidad, pedido desde el celular y recogido en minutos, a precios pensados para el bolsillo universitario.

## Servicios

| Servicio | Descripción |
|---|---|
| Pedidos express | Pedidos por WhatsApp para recoger sin hacer fila |
| Suscripción mensual | Plan prepago de 20 cafés al mes |
| Combos de desayuno | Café más acompañamiento para estudiantes |
| Opciones veganas | Bebidas con leche vegetal |

## Uso de inteligencia artificial

| Herramienta | Uso |
|---|---|
| Adobe Firefly | Logotipo e imágenes de producto |
| Claude | Menú, precios, propuesta de valor y tono de marca |
