# CaféCampus

Cafetería universitaria de café de origen colombiano para estudiantes y docentes con poco tiempo entre clases.

## Propuesta de valor
Café colombiano de origen, listo entre clase y clase: café de calidad, pedido desde el celular y recogido en minutos, a precios pensados para el bolsillo universitario.

## Servicios
- Pedidos express por WhatsApp
- Suscripción mensual de 20 cafés
- Combos de desayuno

## Sitio web
https://simontagdd.github.io/cafe-campus/

## Herramientas usadas
- Adobe Firefly: logotipo e imágenes de producto
- Claude: menú, precios y propuesta de valor
- HTML, CSS y JavaScript: página web
- GitHub Pages: publicación
- Notion: gestión del proyecto
